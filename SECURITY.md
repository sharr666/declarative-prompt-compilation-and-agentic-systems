# Security Policy

This repository is an experimental prompt-compilation and in-process memory prototype. It is not a certified secure compiler or autonomous-agent runtime.

Report suspected vulnerabilities privately through GitHub Security Advisories. Include an affected commit and a minimal reproduction; do not include credentials, personal data or exploit material targeting third parties.

All user-supplied signature fields, demonstrations and retrieved memory records must be treated as untrusted data. The implementation performs schema validation and JSON quoting, but it does not guarantee prompt-injection immunity or general semantic contradiction resolution.
